# 0013 · 评测自动载入机制（v0.0.7）

## 触发（用户反馈）

用户问："为什么 Cognitive Walkthrough 没有帮我载入到评测中？temper 不会自动载入吗？它不应该会分析到这可能是一个评测基准吗？"

这是一个真实 failure mode：评测基准被加进了文档，但 temper 的方法没有"自动把新的可判定标准纳入评测体系"的机制。

## 根因

temper 知道"要评测"（读项目时检查评测），但不知道"评测基准本身是活的、是要被迭代的"。所以下次用 temper，它会读到测试集里有 CW，但不会知道"这是评测基准，我要按它跑、当回归依据"。

这也是 codex 评审说的"证据校准"问题的一个变体。

## 本代改动

| 文件 | 改动 |
| --- | --- |
| SKILL.md | 新增"评测自动载入"（v0.0.7）：每次迭代把评测当被测对象；遇到新的可判定标准→判断有效性（可判定/覆盖盲区/证据可标注）→有效纳入测试集/无效说明原因 |
| 评测/评测说明.md | 重写为完整评测体系（愿景对照+真实反馈+行为测试集+认知走查四维），明确"评测自动载入"是机制非约定 |

## 验证 / 证据

- 机制性改动，不改既有行为。
- 直接解决用户指出的 failure mode：新评测基准会被自动识别并纳入。
- ⚠️ 尚未验证"它真的会自动载入" —— 需要一个新评测标准来测这条机制本身（下一波候选）。

## 版本

- 行为/机制变化，升 v0.0.7（这次是功能代，合理升版本）。
