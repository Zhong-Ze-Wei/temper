# 淬炼（temper）· 设计说明文档

这组文档不是重复介绍同一个东西，而是从彼此正交的几个角度回答“为什么我们要做淬炼”。

建议阅读顺序：

1. `01_为什么要做淬炼.md` —— 问题起点：为什么现有工作方式不够。
2. `02_它到底给谁解决什么问题.md` —— 产品定位：谁会用、为什么会用。
3. `03_为什么它不是自动Loop.md` —— 方法边界：真正被迭代的到底是什么。
4. `04_为什么要这样设计用户体验.md` —— 产品体验：为什么不能把复杂方法论直接暴露给用户。
5. `05_边界_什么时候不该用.md` —— 非目标与适用边界。
6. `06_真实场景如何抽象成这个产品.md` —— 从 AI 应用、数据分析、业务流程三个真实场景看它为什么成立。

一句话总定义：

> **淬炼不是一个“自动循环工具”，而是一套帮助还没完全成熟的任务，在真实运行、反馈、人工判断和版本比较中逐渐变得稳定可用的工作系统。**
