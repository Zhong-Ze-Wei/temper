淬炼temper

你把任务交给它。它带你一轮一轮搞清楚、搞稳定——你只在它真正需要你的地方介入。

不用学任何方法论。说出你的任务，它先读懂你的项目，然后告诉你：现在是什么状态、下一步最值得做什么、需要你给什么。每轮跑完，固定拿到四样东西。

开场只需要说一句（点击复制） 我先看看你现在这个任务做到哪了，再告诉你下一步最值得做什么。

01 · WHAT IT FIXES

它能帮我解决什么

如果你正在经历下面任何一个时刻，它就是为你做的。左边划掉的是现状，右边是它接手之后。

「AI 结果时好时坏，不知道为什么」
它先只读你的项目找出不稳的根源，然后建最小回归集——以后每改一版，好坏有据可比。
「跑了五个版本，说不清哪版更好」
每代给一份人工可读的差异报告：哪些变好、哪些变差、哪些看不出来——逐条链到具体 case。
「需求 / 口径还在变，文档开始失控」
它先找当前事实源、只补缺口不另起炉灶；口径变了显式重开一段，不偷偷换尺子。
「不知道该信 AI 的判断还是自己再看一遍」
它区分「我能自动判断的」和「必须你裁决的」——你只看它圈出来的那几条，不用全检。
02 · IS IT FOR ME

适不适合我

一个判断就够：

✓ 适合，如果……

  • 任务是重复跑的，这次的错误下次还会出现
  • 「怎样做对」还没完全定型，要靠真实反馈逐渐清楚
  • 需要版本之间可比较、可追溯
  • 有些判断只有你或业务同事能做

✕ 不适合，如果……

  • 一次性脚本、确定性转换（CSV → JSON）
  • 人工几分钟就能稳定搞定、偶尔一次的事
  • 没有任何真实反馈来源的问题
  • 纯战略、纯组织问题
它自己的判断标准：下次遇到同类任务，这次留下的证据会不会让结果明显更好？不会的话，它会直接帮你把事做完，不建循环。

04 · FIRST ROUND, LIVE

一轮真实的第一轮长什么样

场景：法规资讯筛选，每周自动跑，结果时好时坏。从「完全不知道它是什么」到跑完第一轮——

你这是我现在的项目，法规资讯筛选，每周自动跑，结果时好时坏。帮我弄稳定。
淬炼 【判断】能跑，但没尺子：方法（prompts/v3.md）里「相关」只有一句话定义，判断全靠模型现场拿捏；两次运行记录只有输出、没存输入，坏 case 没法复现。
【计划】① 我聚类最近运行的错误类型 → ② 起草带判定标准和边界案例的 V4 → ③ 同一批输入跑 V3 vs V4，给你一份差异表。
【需要你】两样：① 业务上最不能接受的错误是哪类？（默认：漏报——该报的没报）② 给我 3–5 条你觉得有代表性的真实资讯。
你漏报最不能接受。这 5 条是我们最近人工核过的。
淬炼 收到，够了。先跑一版 V0——目的不是证明方法好，而是暴露哪些地方我们还不知道。

② 运行记录缺输入原文 → 我处理；
③ 「相关」的边界有 2 条 case 口径冲突 → 需要你。你只需要看这两条：case 03、case 14。（各 1 分钟）

05 · EVERY ROUND

每轮你固定拿到什么

四样东西，每轮都有，一样不少——哪天少了一样，就是它的 bug。

①
结果

这轮做了什么，产物在哪。

②
差异

和上一版比：变好 / 变差 / 看不出来，逐条链到 case。

③
建议

采用 / 不采用 / 再跑一代，附理由和证据等级。

④
待你确认

最多 1–2 件，每件带默认推荐——回「行」就走。

06 · DO I NEED TO LEARN ANYTHING

我需要先学点什么吗

不用。方法论是淬炼自己的，不是让你学的。

你只需要看到：现在是什么问题 → 它准备怎么做 → 你现在要做什么 → 做完发生了什么 → 下一步。下面这些是它的内部机制——好奇再点开，不点完全不影响使用。

它怎么保证不偷偷换标准？
一段时间内「什么叫做对」被冻结，只迭代「怎么做」；如果目标或口径真的变了，它会显式宣布重开一段并告诉你哪些历史结果还能比，而不是悄悄改尺子后继续声称新版更好。
它说「采用了」就等于「验证过」了吗？
不。它严格区分三个版本：工作版本（日常演进，可逆）、业务校准版本（业务确认过）、生产版本（对外跑着）。更新一个不自动更新另一个——便宜证据推不动业务确认。
它凭什么说「变好了」？
证据分六层，从结构校验到业务打标可信度递增。它会告诉你当前结论站在哪一层证据上——便宜证据只支持继续试，说「业务上变好了」必须高层证据。
什么时候必须我出面？
四类节点：方向确认、拍板、业务裁决、高风险判断。其余它自己扛。随着任务成熟，你的介入只会越来越少——人机边界本身也是被它持续优化的对象。
它会乱建文件、动我的项目吗？
进入时只读；要建结构会先给「复用 X / 新增 Y」清单等你批准；现有文件能承载就更新现有的，不另起炉灶。你只要分析不要动手时，它给完判断就停。

07 · START NOW

立刻开始第一轮

JUST SAY ONE LINE

在支持 Skills 的 Agent 里输入 $temper，或者直接这样开口：

「这是我现在的项目，帮我看看怎么把结果弄稳定」
「这任务跑了几个版本了，说不清哪版好」
「我有个想法，还不知道怎么做成能交付的方法」

然后它的第一轮回应固定长这样：
【判断】你现在的状态 + 一句为什么（引用项目里的真实文件，不空谈）
【计划】接下来 2–3 步，每步说清产出什么
【需要你】最多 2 样东西，每样带默认——你回「行」即走，回改即调

随时可以说「先只分析，什么都别动」——它会停在只读。每轮最多拍一次板，这就是全部负担。
