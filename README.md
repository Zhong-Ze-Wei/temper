## 怎么用这个仓库

把任务直接说给它听即可。它每次冷启动会按序读：权威区 → 过程区最新一代 → 冻结区尺子 → 状态文件，然后先说"我理解的现状"再动手。

你只需要：

1. 给真实任务和"什么算好"的案例；
2. 被问到业务口径时给一句话裁决；
3. 每版给一句验收（收 / 退）；
4. 感觉方向不对，直接说"偏了"。
