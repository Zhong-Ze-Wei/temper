## 怎么用这个仓库

把它当普通任务交给 temper 就行，说一句"用 temper 迭代 temper 自己"。它会自己走一遍：看现状 → 定这轮要干嘛 → 改 → 拿尺子量 → 给你看 diff。

你只需要：

1. 每次进来先看这个 README 的"一眼看懂"块，就知道现在到哪了。
2. 想快速知道"改了什么"，看 [版本/版本说明.md](版本/版本说明.md)。
3. 需要你决策的时候，它会在 README / 状态里明确标出来。
4. 觉得它说话绕，直接说"讲人话"。
